# dc-veille-ao-ami-data

Fichier de données publié automatiquement par une routine quotidienne (Claude Code) pour alimenter l'outil interne de suivi des appels d'offres de Dakar Construction.

`offres-web.js` contient uniquement des informations publiques sur des appels d'offres/AMI (titre, client, pays, type, lien source, échéance). Aucune analyse stratégique interne n'est publiée dans ce dépôt.

Ce dépôt est un simple support technique de synchronisation — il n'est pas destiné à être consulté directement.
